## 修正结论

此前默认 curl 在四个功能地址收到 500，不能据此认定用户无法使用页面。真实 Chrome 复核确认五项功能的中英文页面可打开；请求结果还会随语言、Cookie 和时间变化。曾出现功能地址返回 200 却跳到中文首页，不能把这种响应算作功能页可访问。

恢复生成、美化、批量、优化四项功能的中英文链接，加上原有解析入口共五项。公开文案改为实际使用提示：遇到加载异常可从工具箱首页重试，中文仍有未翻译标签。二维码内容编辑日期更新为 2026-10-19。未修改二维码站或 Tiny Image 源码，浏览器能加载页面不等于所有生成/下载功能已验收。

## 检查方式

- `check:links` 使用 HTML Accept、明确语言、标明身份的 User-Agent、每个 URL 隔离的临时 Cookie；Cookie 在同一地址的跳转/重试间保留，结束后删除，不写入证据或仓库。
- 最多三次请求，最多四个并发；保留每次状态和目的地。200 跳首页、换语言或换域名不通过，仅允许尾斜杠规范化；JSON 等非 HTML 响应不通过。
- `check:links:browser` 使用独立 Chrome 会话和对应语言，核实初始 HTTP 目的地、JavaScript 执行后的地址及非空页面。`--host=qr.tinystool.org` 可限制范围；浏览器必须已安装。
- HTTP 与浏览器证据分开保存。HTTP 失败仍阻止完整 generate；浏览器复核不自动覆盖失败，也不自动隐藏项目。
