# Owner 最小决策清单

只需要这些人工信息。Codex 如暂时无法联系用户，应按“保守默认”先做可执行功能，不要中断全部工作。

- [ ] **公开展示名**：默认 `TMY`，避免在未经许可时使用真实姓名。
- [ ] **公开 GitHub 账号**：未确认 → 不展示 GitHub 按钮及 sameAs。
- [ ] **公开邮箱/联系方式**：未确认 → 不展示私人邮箱，Contact 改为待补信息。
- [ ] **网站语言**：默认英文单语言；等有可靠翻译后再引入中文。
- [ ] **技术选型**：默认 Nuxt 4（Nuxt 3 EOL）；如明确坚持 Nuxt 3，需接受维护风险与迁移计划。
- [ ] **QR 站是否可公开**：本次未验证 → 保持 draft，人工检查后按发布流程升级。
- [ ] **OurTable 小程序**：是否真实已上线、作者是否同一人、是否希望公开 → 未确认则不发布。
- [ ] **IP 检测 / 图片压缩 / H5 游戏**：现阶段按规划处理；完成后再补真实链接、截图、说明。
- [ ] **是否允许 Tiny's Tool 反向署名**：默认不修改其任何源码；确认需要后，再在 about 页自然增加一条链接。
- [ ] **隐私分析或监控**：默认不接入任何第三方访客分析。
